📐 K-Score 6-Axis Formula & Methodology

K-Rank completely eliminates subjective voting, manipulation, and paid voting fees. We calculate objective K-Scores (0-100) using 100% verified global fact metrics: Spotify, Circle Chart, YouTube, SNS, Google Trends, and real-time fandom power.

K-Score = (0.30 × S_Music) + (0.25 × S_Album) + (0.20 × S_YouTube) + (0.15 × S_SNS) + (0.05 × S_Buzz) + (0.05 × S_Power)

🎵 1. Global Music Stream Index (30%)

Spotify Web API Global Daily/Weekly Charts & Apple Music Global Streams.

💿 2. Album Sales Index (25%)

Circle Chart Official Album Sales (1st-week & cumulative physical album sales).

📺 3. YouTube Video Index (20%)

YouTube Data API v3 verified Official Music Video views, likes & engagement growth.

📲 4. Social Growth Index (15%)

Instagram & X (Twitter) global follower weekly growth & media mentions.

🔍 5. Google Global Buzz Index (5%)

Google Trends API worldwide search volume & global interest trends.

🔥 6. Real-Time Fandom Power (5%)

K-Rank 3-Layer anti-duplicate verified real-time 1-click cheer logs.

🛡️ Anti-Duplicate Voting Prevention

To prevent bot spamming and macro manipulation, K-Rank utilizes HttpOnly Cookie (krank_vid) + Client IP/UA SHA-256 dual verification to enforce a 24-hour single-cheer limit per artist.
