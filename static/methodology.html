📐 K-Score 6대 가중 산출 수식

K-Rank는 주관적 인기 투표, 조작 가능성, 유료 투표 결제를 전면 배제하고, 글로벌 공식 팩트 지표(Spotify, Circle Chart, YouTube, SNS, Google Trends, 실시간 응원)만을 100점 만점으로 정량 산출합니다.

K-Score = (0.30 × S_음원) + (0.25 × S_음반) + (0.20 × S_유튜브) + (0.15 × S_소셜) + (0.05 × S_구글버즈) + (0.05 × S_화력)

🎵 1. 글로벌 음원 지수 (30%)

Spotify Web API 글로벌 일일/주간 차트 스트리밍 재생수 및 Apple Music 글로벌 차트 정량 반영.

💿 2. 음반 판매 지수 (25%)

Circle Chart (구 가온차트) 공식 데이터 기반 앨범 초동 및 누적 음반 판매량 정량화.

📺 3. 유튜브 영상 지수 (20%)

YouTube Data API v3 연동 official 뮤직비디오 조회수, 좋아요, 댓글 증가율 정량 집계.

📲 4. 소셜 성장률 (15%)

Instagram 및 X(Twitter) 글로벌 팔로워 주간 증가량 및 공식 키워드 언론 언급량.

🔍 5. 구글 글로벌 버즈 (5%)

Google Trends API 기반 전 세계 포털 검색 관심도 트렌드 지수.

🔥 6. 실시간 팬덤 화력 (5%)

K-Rank 자체 3중 중복 방지 연동 1클릭 실시간 하트 응원 로그 수 스케일링.

🛡️ 중복 부정 응원 방지 메커니즘

K-Rank는 매크로 및 매니아 팬덤의 부정 연타 응원을 방지하기 위해 HttpOnly Cookie (krank_vid) + Client IP/UA SHA-256 해시 듀얼 검증 시스템을 운영하며 24시간 동안 중복 투표를 원천 차단합니다.
